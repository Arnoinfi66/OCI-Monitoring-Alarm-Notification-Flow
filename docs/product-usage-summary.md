# Product Usage Summary

## Product Used

Oracle Cloud Infrastructure Monitoring and Notifications

---

## Purpose

This repository explains the basic flow between OCI Monitoring alarms and OCI Notifications.
The focus is to explain how metrics, MQL queries, alarm conditions, notification topics, and subscriptions work together.

---

## What I Created

I created a structured documentation repository covering:

- Monitoring alarm flow
- Notification delivery flow
- Metrics and namespaces
- Alarm query and trigger behavior
- Notification topic and subscription flow
- Alarm severity and review
- Product usage summary

---

## What I Understood

My main understanding is that monitoring should be reviewed as an end-to-end flow.
The metric shows the resource behavior. The MQL query defines what should be checked. The alarm condition decides when attention is needed. The notification topic and subscription send the alert to the user.
If one part is missing or incorrect, the monitoring setup may not work properly.
